# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in TikTokExplode, please report it privately through GitHub Security Advisories. Do not disclose security issues in public repositories, issues, or pull requests.

## Supported Versions

- Current stable version: 1.4.7
- Previous versions: 1.4.6, 1.4.5, 1.4.4, 1.4.3, 1.4.2, 1.4.1

## Expected Response Time

We aim to respond to security vulnerability reports within 7 days and provide a fix within 30 days.
