# Contributing

Thank you for considering contributing to TikTokExplode! This document outlines the contribution process and guidelines.

## How to Start

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Ensure the build passes: `dotnet build TikTokExplode.sln`
5. Run tests if available
6. Commit your changes with a descriptive message
7. Push to your fork and submit a pull request

## Reporting Bugs

When reporting a bug, please include:

- Version number (e.g., 1.4.7)
- Platform (.NET version, OS)
- Steps to reproduce
- Expected vs actual behavior
- Any relevant logs or screenshots

Example template:
```
Version: 1.4.7
Platform: .NET 9.0 on Windows 10
Steps to reproduce:
1. ...
2. ...
3. ...

Expected: ...
Actual: ...

Logs:
...
```

## Feature Requests

For feature requests, please:

1. Check existing issues to avoid duplicates
2. Provide a clear problem statement
3. Describe the proposed solution
4. Explain any alternatives considered
5. Add any additional context

## Pull Request Process

1. Ensure your PR addresses an existing issue (link to it)
2. Write clear, logical commits
3. Follow conventional commit messages
4. Ensure tests pass before submitting
5. Review your changes before opening the PR

## Code of Conduct

Please refer to [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) for our community guidelines.

## Style Guidelines

- Follow existing code style
- Write clean, idiomatic C# code
- Add documentation for new public APIs
- Keep changes focused and minimal
